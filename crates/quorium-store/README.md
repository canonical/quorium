# quorium-store

The shared write-ahead log behind openraft's log storage, with group commit and compaction, and state checkpoints.

This crate is an internal part of [Quorium](https://crates.io/crates/quorium). Its API follows Quorium's releases and carries no stability promise of its own; depend on `quorium` instead.
